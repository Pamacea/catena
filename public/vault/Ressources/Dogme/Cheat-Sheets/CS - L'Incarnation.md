# ⚡ Cheat-Sheet — L'Incarnation

---

## 🧠 Formule fondamentale

```
JÉSUS-CHRIST = DEUX NATURES en UNE SEULE PERSONNE
Nature divine (éternelle, infinie) + Nature humaine (créée, finie)
Personne unique : le Verbe (2ème Personne de la Trinité)
```

**Sans confusion** (anti-monophysisme), **sans changement** (anti-docétisme), **sans division** (anti-nestorianisme), **sans séparation** (anti-arianisme).

---

## 🔑 Les 2 Natures du Christ

| | Nature Divine | Nature Humaine |
|:--|:-------------|:--------------|
| **Personne** | Le Fils (Verbe) | Le Fils (Verbe) |
| **Corps** | Aucun | Vrai corps |
| **Âme** | Aucune | Vraie âme humaine |
| **Intelligence** | Infinie | Finie |
| **Volonté** | Infinie | Finie |
| **Science** | Béatifique, infuse | Acquise, expérimentale |
| **Immortalité** | Éternelle | Mortelle (glorifiée après Résurrection) |

---

## 📖 Exemples d'actions selon les natures

| Action | Nature opérante | Pourquoi |
|:-------|:----------------|:---------|
| Ressuscite un mort | **Divine** | Seul Dieu donne la vie |
| A soif | **Humaine** | Besoins du corps |
| Pleure sur Lazare | **Humaine** | Émotion |
| Pardonne les péchés | **Divine** | Seul Dieu pardonne |
| Souffre et meurt | **Humaine** | La Passion est réelle |

## 🚫 Hérésies Christologiques

| Hérésie | Erreur en 1 mot | Condamnation |
|:--------|:----------------|:-------------|
| **Docétisme** | Illusion — le corps n'est pas réel | Nie la vraie chair |
| **Arianisme** | Créature — le Fils n'est pas Dieu | Nicée (325) |
| **Nestorianisme** | Deux personnes — Marie n'est pas Mère de Dieu | Éphèse (431) |
| **Monophysisme** | Fusion — une seule nature | Chalcédoine (451) |
| **Monothélisme** | Une volonté — pas de volonté humaine | Constantinople III (681) |

---

## 📖 Les 4 Sciences du Christ

1. **Science béatifique** — vision de Dieu face à face (dès la conception)
2. **Science infuse** — connaissance immédiate des vérités (dès la conception)
3. **Science acquise** — apprentissage humain progressif
4. **Science expérimentale** — connaissance par les sens
